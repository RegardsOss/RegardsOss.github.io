## Breaking change

### Deployment

### GeoJson products (microservice: rs-Fem)

All requests with a status of ‘SUCCESS’ that are used to reference a file or physically store a file using the
`rs-storage` microservice are no longer saved in the `rs-fem` microservice’s database. Only requests with a status of
‘ERROR’ are saved in the `rs-fem` microservice’s database.

### Rest API

The OAIS product deletion REST API (microservice rs-ingest - URL: /api/v1/rs-ingest/aips/delete) using the HTTP verb
*POST* is deprecated. A new OAIS product deletion REST API using the HTTP verb *DELETE* is now available at the same
URL.

### AMQP API

### URL validation

Modify the validator to check the URLs of all files contained in a REGARDS product (check performed in rs-Storage
microservice).

    The URL must start with a protocol (http, https, file, staf, s3, regards protocol ..etc..)
    The URL must not contain an anchor (# character)
    The URL may contain parameters (? character) for the query URL

Example valid URLs :

- http://my.domain.fr/directory/file.dat
- http://my.domain.fr:123/directory/file.dat
- https://my.domain.fr/directory/file.dat
- https://my.domain.fr:8080/directory/file.dat
- http://rs-minio:9000/glacier-t3/2026/3/31/lta-product-003/20260331200153063.zip?fileName=product3.zip
- https://som.site.esa.fr/mission/data?retrieval_type=LAST_PRODUCT&data_item_oid=201&product_type=METEO&data_retrieval_origin=MAP
- file://my.domain.fr/directory/file.dat
- file:///my.domain.fr/directory/file.dat
- file:/my.domain.fr/directory/file.dat
- staf://project/node/file.tar?fileName=file.dat
- staf://project/node/file.dat?parts=12
- s3://bucket/directory/file.dat
- s3://bucket/directory/toto?filetoto
- regards://validation/local/2026/4/1/lta-product-021/fb8613574312c47f215343ebebaf8ebf

Example not valid URLs :

- http://my.domain.fr/directory/file#.dat
- http://my.domain#.fr/directory/file#.dat
- https://my.domain.fr:8080/directory#/file.dat
- /my/file.dat
- file:///dir/file#.dat
- s3://bucket/directory/toto#filtoto
- invalid_scheme://my.domain.fr/directory/file.dat
- ma.bucket-directory_toto/test

## Bug fixes

- rs-authentication
    - Fixes an issue related to the configuration of the user authentication token duration in the application

- rs-catalog
    - Fixes issues with the download and the CSV export modules by adding filters based on access rights

- REGARDS User UI
    - Fixes an issue concerning the date/time criteria in the search form panel. These criterias are now refreshed when
      clicking the REFRESH button.

- rs-ingest
    - Fixes an issue concerning the REST API payload used to delete OAIS products, reducing the risk of a malformed
      payload resulting in the deletion of all products from the REGARDS catalogue.

- rs-fem
    - Fixes an issue concerning the REST API payload used to delete GeoJson products, reducing the risk of a malformed
      payload resulting in the deletion of all products from the REGARDS catalogue.

- rs-order
    - Fixes an issue that could occur when creating many orders while downloading other orders at the same time.

- rs-storage
    - Fixes an issue related to the mass deletion of file by optimizing the deletion process
