Version 2.5.0

Released on : 14/10/2026
Operational version

Features​

Inter-REGARDS: Remote REGARDS storage plugin​

The new plugin remote-regards-storage-plugin allows products to reference files that are stored on another REGARDS instance.

The documentation for this plugin is available here.

Direct AIP dissemination through AMQP​

rs-ingest can now receive AipDirectDisseminationEvent messages to disseminate AIPs identified by their providerId to a specified rs-notifier recipient. Requests are grouped by recipient and bypass notification rule filters. The recipient must have directNotificationEnabled enabled.

See the rs-ingest documentation.

OAIS deletion through AMQP and Notifier​

rs-ingest can now receive AipDeletionEvent messages to delete all versions of an OAIS product identified by its providerId, either irrevocably (IRREVOCABLY, the default) or by marking them as deleted (BY_STATE).

The new rs-notifier plugin rs-oais-deletion-sender-plugin (OaisDeletionRequestSender) generates these requests from AIP notifications. It supports a target tenant on the same REGARDS instance or on another instance through a RabbitMQ shovel.

See the rs-ingest documentation and the Notifier sender plugins.

Configurable LTA file datatype mapping​

The lta-product-zip-extraction-worker now supports the lta.product-zip-extraction.extension-to-types configuration to map file extensions to REGARDS datatypes. The default configuration preserves the previous behavior: jpg, jpeg and png map to QUICKLOOK_SD, while extensions without a mapping default to RAWDATA.

See the LTA Manager documentation for configuration details.

Breaking change​

AMQP Exchange regards.storage.file.notification​

The exchange regards.storage.file.notification is no longer broadcasting events with the routing key regards.file.availability.status. Instead, it now uses different routing keys depending on the project that is involved in the event. The new routing key is regards.storage.file.notification.<project>, where <project> is the project name where the event has occurred.

The strategies to adapt to the new routing key are presented in the migration guide.

Deployment​

You need to follow the Ansible migration guide to update your playbook from V2.4 to V2.5.

Frontend staticConfiguration.js is no longer provided​

The frontend configuration must now be provided at deployment time.

See the migration guide for the required changes.

Rest API​

Service configuration​

AMQP API​

rs-ingest adds two event interfaces:

  • AipDirectDisseminationEvent, with providerId and recipient fields.
  • AipDeletionEvent, with providerId and optional deletionMode fields.

Neither interface provides dedicated AMQP request status responses. Dissemination can be monitored through the AIP's dissemination information; deletion notifications require rs-ingest product notifications and a matching rs-notifier rule and recipient.

A framework and a set of plugins to build scientific archives.

REGARDS is an Open Source data valorization product, highly flexible to various themes, modular, efficient, long-lasting, evolutionary and scalable, aims at providing services to Mission Centers and laboratories, and is able to deal with huge amount of data.
Our goal is to allow a strong commitment from user community in the development of modules and plugins.

We welcome your contributions to make these documents better.
